Helix

2025

Self-Hosted Localhost Tunneling Tool

View Live View Code
H
Node.jsTypeScriptCLISelf-HostedNetworking

The Challenge

Existing tunneling tools hand out disposable subdomains on every restart, offer no self-hosting story, and charge for basics like persistent URLs.

The Solution

Built Helix around path-based routing instead of subdomains — every tunnel lives at a persistent /tunnel/{name}/ path on a self-hosted relay with passwordless email-code auth.

Impact

  • •Delivered a working ngrok alternative with zero ongoing hosting cost
  • •Solved relative-URL rewriting for path-based tunneling

Key Features

Path-based persistent tunnels (/tunnel/{name}/) instead of disposable subdomains

Self-hosted relay — traffic stays on infrastructure you control

Passwordless email-code authentication across CLI and web

Live request history dashboard & password-locked tunnels

Tech Stack

Node.js relay server + CLI client, TypeScript
Appwrite for auth/data & GitHub OAuth

Lessons Learned

  • →Path-based routing is viable when relative asset URLs are rewritten server-side
  • →Shipping a full product in 4–5 days is possible with tight scope discipline

patterns — how pages are composed across light & dark mode.

home and case studies sit on --t-bg (#efefef light / #0d0e0e dark); blog index and article pages use the slightly brighter --t-bg-reading (#fbfbfb light / #111212 dark) for reading comfort. set data-theme="dark" or class="dark" on <html> to flip the entire 11-step ink opacity ramp.

do

  • write everything in lowercase; end headings with a period or "...".
  • build hierarchy with ink opacity (100 / 80 / 70 / 65 / 50 / 35).
  • use .t-rails--wide (left-40 / right-40) on max-w-4xl case study pages.
  • use speech-bubble corners (rounded-2xl rounded-tl-sm) on blog comments.
  • make every control a pill; put cards inside an inset well.
  • use semantic tokens (--t-fg, --t-surface, --t-ink-70) so dark mode works automatically.

don't

  • introduce brand colours, blue links or coloured buttons.
  • use lime anywhere except the footer wordmark (at 30%).
  • hardcode #fff or #151515 on cards or text that need to invert in dark mode.
  • set display type with loose leading; lines should nearly touch.
  • use Caveat for body copy, UI labels or anything under 20px.
  • exceed the single-column container or add sidebars.
